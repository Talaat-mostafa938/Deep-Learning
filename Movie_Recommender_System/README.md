# 🎬 Movie Recommender Engine with Posters

This is a simple and effective movie recommendation system built using **Streamlit**, **pandas**, and **scikit-learn**. It recommends movies based on **genre similarity** using natural language processing (TF-IDF and cosine similarity).

---

## 🔍 Features

- 🎥 Recommend top 5 similar movies based on genre
- 🧠 Uses TF-IDF vectorization and cosine similarity
- ⚡ Built with **Streamlit** for interactive and easy-to-use UI

---

## 📦 Tech Stack

- Python 3
- pandas
- scikit-learn
- Streamlit
